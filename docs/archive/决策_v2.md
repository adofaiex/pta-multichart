## 2. P2 怎么选

按这个顺序，不能跳。

1. 打开 `实现摘录_v1.md`。确认两套读数就是 A1 = `ideal − natural`、A2 = `need − carry`，并且摘录里的第二个 PT-1 测值是 (-0.5, 0.5)、A1 是 (-0.5, 1.5)。有第三套读数，或这四个数对不上，停。把摘录原句抄进对照表，不选边。
2. 确认 (-0.5, 0.5) 是当前编译器写出的那条 PositionTrack，而不是改完代码之后的数。对不上编译器输出，先停，写明这个数来自哪一份产物。只有「数不在编译器输出里、只在桥的抓取里」时，才进入 T3。
3. 对照表每一行三列：A1、A2、当前编译器写出的偏移。行至少包括：第二个 PT-1；以及至少一个 A1 和 A2 数值不同的后续 split。现有 5 张谱里能出现这种 split 的，都放进表。
4. 现有谱制造不出差开的 split 时，允许加一条固定夹具，只用来让两套公式分叉，再让当前编译器编译它。夹具不得改变那 5 张谱的编译结果。夹具不进游玩回归。
5. 某一套读数必须每一行都等于编译器，才能冻结。命中的是描述，不是修改许可。
6. 没有任何一套全中：不发明 A3，P2 继续未冻结，不改 `方案_v2.md`，第三轮结束。
7. 全中的那一套写入方案时，只替换 P2 节里仍写着「未冻结 / 待回填 / 两套并存」的句子，附上对照表路径。不重写方案其他节。
